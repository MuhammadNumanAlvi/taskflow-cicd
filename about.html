Purpose

TaskFlow is a lightweight task-management application created for practicing DevOps CI/CD pipeline integration.

Application demonstrates how a web project can be containerized with Docker and automatically delivered using GitHub Actions and Render.

How to Use

Use the Dashboard to see task summary counts and navigation links.

Use the Add Task page to enter task title, description, due date, and priority.

Use the Task List page to view tasks and filter them by status.

Use the Task Detail page to view complete information about one task and perform actions such as complete or delete.
